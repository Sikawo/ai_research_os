# Verified Search Changelog

This file records policy versions, not implementation sessions or daily work.

## v1.2.0 deployment fix - 2026-08-05

- compressed the controlling Custom GPT Paste-Ready Instructions below the
  8,000-character platform limit without changing the canonical Core;
- adopted the intended Custom GPT split between compact controlling
  Instructions and current Core, acceptance tests, and UX Knowledge files;
- added automated exact-block character validation with an independent safety
  budget for each deployment surface;
- made over-limit artifacts ineligible for the `Paste-Ready` label.

## v1.2.0 - 2026-08-04

Generalized how Verified Search determines which authoritative artifact currently governs a decision, introducing:

- an explicit distinction between publication freshness, effective applicability, and governing relationship;
- Continuing Applicability and Supersession as a symmetric normative check;
- materially later revalidation for temporary, exceptional, transitional, emergency, and open-ended artifacts;
- safeguards against both `newer wins` and `older specific wins forever`;
- stronger conflict, Negative-Claim Guard, dynamic-source inspection, and Final-Action Audit behavior;
- canonical-current-artifact routing without mandatory multi-source or ceremonial searching;
- generalized administrative-procedure tests plus the indefinite-closure specialization;
- synchronized Core, UX, Custom GPT, Custom Instructions, setup, and repository guidance.

## v1.1.0 - 2026-08-03

Extended Verified Search from factual verification to decision-ready verification, introducing:

- decision-ready positioning;
- Best-Action Principle;
- Decision Framing;
- Failure-Mode First;
- Temporal Relevance;
- Re-check Planning;
- a structured single-model multi-pass workflow;
- meaningfully independent evidence verification;
- Action Audit and Action Readiness;
- Mandatory Source URL Policy for visible inspected URLs;
- `Actually Checked` as the recommended user-facing Custom GPT name;
- a full Custom Instructions deployment variant;
- expanded decision, timing, independence, URL, and usability tests.

## v1.0.0 - 2026-08-02

Initial canonical release of Verified Search, introducing:

- Verified Search Baseline;
- Strict Verification;
- Final-Action Audit;
- Entity Lock;
- Date Lock;
- Freshness Check;
- claim-specific Source Authority routing;
- official social-media provenance checks;
- Claim-Level Verification and verification statuses;
- the No-Fill Rule;
- the Negative-Claim Guard;
- applicability and conflict handling;
- Source Coverage instead of confidence percentages;
- multilingual parity without translated policy forks;
- Custom GPT and compact Custom Instructions deployment artifacts;
- repository integration while preserving scientific Evidence-Gated Research Discussion.

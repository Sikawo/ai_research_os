# Evidence Mode

Use the reviewed prompt in
`references/evidence_gated_research_discussion_prompt.md` as the operating
contract. Work only with material supplied by the user or public sources the
user has authorized. Distinguish observations, interpretations, hypotheses,
and decisions. Preserve uncertainty and stop before protected-content access,
external writes, or consequential actions that need separate approval.

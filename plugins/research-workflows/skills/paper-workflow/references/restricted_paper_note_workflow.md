# Restricted Paper Stop Rule

Restricted manuscripts and notes are outside this public plugin.

Stop when material is unpublished, under review, confidential, embargoed,
licensed for limited use, reviewer-confidential, or collaborator-private. Do
not read, summarize, OCR, hash, copy, move, rename, upload, or transform it with
this plugin. Do not create a restricted-content folder or store restricted
metadata here.

If the work is later published, start a new public workflow from the published
version. Never sanitize a restricted internal note into a public note by merely
deleting selected details.

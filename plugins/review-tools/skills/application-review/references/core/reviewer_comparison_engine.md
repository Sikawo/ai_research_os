# Reviewer Comparison Engine

## Purpose

Stress-test architecture candidates using allowed reviewer lenses and the
target rubric after scientific admission. The goal is to choose the option most
likely to improve review outcome without replacing scientific judgment with
familiarity or smooth prose.

## Scientific argument prerequisite

For eligible proposals and research plans/statements, use
`plugins/review-tools/skills/application-review/references/core/scientific_argument_gate.md` and its report template.
Carry each candidate's current argument readiness, evidence, and unresolved IDs
into the comparison. Improvement over Candidate 0 is separate from adequacy.
Do not select a superficially polished candidate by averaging away an essential
motivation or focus failure. Scientific admission and human edit gates remain
unchanged. Optional criterion scores require evidence and a counterconcern check;
keep portfolio importance, argument quality, voice/tone, and risk scales distinct.

## Required Axes

Assess each candidate for:

- reviewer clarity;
- over-scope risk;
- feasibility risk;
- independence risk;
- institution-fit risk;
- evidence strength;
- expected evaluation gain;
- risk of weakening the applicant's strongest identity.
- whether the scientifically strongest candidate is communicable;
- whether narrative simplification removes the conceptual advance;
- whether reviewer-risk reduction makes the science more generic;
- whether an unconventional candidate survives specialist scrutiny;
- whether the baseline is preferred merely because it is familiar;
- whether the candidate creates a meaningful new prediction;
- whether the difference is new science or only new wording;
- whether the program and each Aim/project opening communicate why the work
  matters before methods or dense technical detail, without unsupported impact
  inflation or repetitive boilerplate;
- for scientific applications, whether an overview visual orients the reviewer
  early and the visual sequence mirrors the argument;
- whether each substantive page has a clear narrative job and later figures
  resolve the correct reviewer doubts;
- whether applicant ownership remains visible in the visual story;
- whether the central argument is reconstructable in 60 seconds without body
  text and leaves a distinctive five-minute memory trace;
- whether the figure sequence builds a coherent cumulative argument.

Reviewer familiarity is not scientific superiority. Preserve each candidate's
Scientific Coherence Firewall verdict, scientific class, scientific/narrative
space label, and literature-novelty status during comparison. Visual ease must
not outrank scientific coherence, evidence strength, or feasibility.

## Reviewer Lens Rules

- Use saved reviewer lenses only when the task scope permits them.
- Treat reviewer backgrounds as field-informed perspectives.
- Do not impersonate real reviewers.
- Do not claim actual reviewer assignment or private reviewer opinions.
- Preserve Reviewer Lens Locked Mode behavior when a reviewer profile is used.

## Output

Use `plugins/review-tools/skills/application-review/assets/templates/reviewer_comparison_scorecard_template.md`.
Record the chosen architecture and rejected alternatives in the revision
decision log.

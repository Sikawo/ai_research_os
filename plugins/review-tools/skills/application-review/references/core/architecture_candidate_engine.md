# Architecture Candidate Engine

## Purpose

Express already evaluated scientific models as multiple possible application
architectures before editing. Scientific exploration occurs upstream; this
engine is not the first location where high-upside scientific alternatives are
created. The current structure is treated as one candidate, not as the default
winner.

## Inputs

Receive:

```text
baseline scientific model
+
scientifically admitted alternative models
```

Never promote a Speculative Seed or Reject into the current scientific story.
If no unconventional candidate survives, generate narrative candidates around
the baseline without fabricating scientific novelty.

## Candidate Requirements

Generate 3 to 5 candidates:

- Candidate 0: current structure or closest faithful baseline.
- Candidate 1: strongest clarity-first structure.
- Candidate 2: strongest reviewer-risk-reduction structure.
- Candidate 3: strongest institution-fit or rubric-fit structure when useful.
- Candidate 4: optional high-upside structure if enough evidence supports it.

For each candidate, include:

- project order;
- project weighting;
- central narrative spine;
- what becomes core;
- what becomes supporting;
- what becomes decision-gated;
- what becomes future direction;
- what improves;
- what is sacrificed;
- implementation difficulty.
- difference-space label: `scientific`, `narrative`, or `both`;
- source scientific candidate ID and firewall verdict;
- scientific insight magnitude and candidate current edit magnitude.

For scientific applications, also include:

- the narrative job of each substantive page or section;
- whether an overview figure can orient the reviewer early;
- whether the visual sequence mirrors the argument sequence;
- which reviewer doubt each later figure resolves;
- whether applicant ownership is visible in the visual story;
- whether a 60-second reviewer can reconstruct the full argument;
- the likely five-minute memory trace;
- whether the figure sequence creates a coherent cumulative argument.

## Selection Rule

Prefer the architecture that best preserves the strongest admitted science and
communicates it after penalties for over-scope, feasibility risk, weak evidence,
independence risk, and damage to the applicant's strongest identity. Do not
prefer the baseline merely because it is familiar or an alternative merely
because it is surprising. A narrative reorder is narrative novelty only. Do not
choose scientifically weaker architecture merely because it is easier to draw.
Scientific coherence and evidence remain upstream of visual optimization, and
Candidate 0 remains the required baseline.

# Writer Mode

## Purpose

Improve language, tone, flow, and reviewer readability without changing
scientific meaning.

Writer Mode is a prose mode. It is not a project-architecture mode and not a
scientific-review mode.

## Focus

- English clarity
- paragraph flow
- non-native or awkward phrasing
- overly generic or AI-like language
- overclaiming
- senior-scientist tone
- concise but specific phrasing

## Required Output

1. Tone diagnosis
2. Sentences that sound weak or non-native
3. Minimal edits
4. Stronger application edits
5. Warnings where meaning may change
6. Revised text if requested

## Rules

- Do not change scientific meaning unless explicitly marked.
- Do not restructure projects.
- Do not add new experiments unless requested.
- Preserve uncertainty and caveats.
- Provide minimal edits and stronger application-style edits when useful.

# Rubric & QC Mode

## Purpose

Check target-specific requirements and final consistency.

This mode combines rubric compliance and final QC. Do not create separate
rubric, compliance, and QC modes unless a future approved redesign changes the
four-mode system.

## Check

- eligibility
- application requirements
- required sections
- page limits
- budget and staffing constraints
- mission or institute fit
- evaluation criteria
- project numbering
- figure numbering
- table consistency
- status consistency such as accepted / in revision / published
- consistency across proposal, publication list, past research, rationale, CV,
  and other package documents
- formatting risks
- final submission risks

## Required Output

1. Non-negotiable compliance issues
2. Major consistency issues
3. Minor QC issues
4. Cross-document inconsistencies
5. Required fixes before submission
6. Optional improvements

## Rules

- Mark unknown requirements as unknown rather than inventing them.
- Separate official requirements from working assumptions.
- Do not read protected package documents unless explicitly authorized.
- Do not rewrite application text unless the user switches to Writer Mode.

# Generic Manuscript Rubric

Use this when no journal-specific rubric has been approved.

## Core Criteria

- Clear central claim.
- Evidence supports the claim without overreach.
- Novelty and field relevance are visible early.
- Methods and limitations are represented accurately.
- Figures, tables, and references support the narrative.
- Reviewer objections are anticipated.
- Title, abstract, introduction, results, discussion, and cover letter align.

## Sprint QC Checks

- No unsupported claims.
- No fabricated citations or results.
- Figure references and captions are consistent.
- Limitations are not hidden by polish.
- Claims are calibrated to available evidence.

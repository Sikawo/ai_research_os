# Word Figure Placeholder

Use this template only when a figure is useful but no authorized finished figure
exists. Render it as a stable inline one-cell Word table when practical.

```text
Figure [number or ID]. [Concise title]

Reviewer question answered
[One important reviewer question that this visual resolves.]

Take-home message
[One evidence-calibrated sentence stating what the reader should understand.]

Suggested content/layout
- Left or Panel A: [authorized concept, observation, or current model]
- Center or Panel B: [relationship, transition, workflow, or comparison]
- Right or Panel C: [authorized prediction, outcome category, or decision point]

Suggested figure type
[Conceptual schematic / model comparison / Aim map / decision tree / timeline /
other justified form]

Evidence boundary
[Published result / preliminary result / hypothesis or model / proposed
experiment / expected outcome / future implication / other source-supported
status]. Concept-only placeholder. No invented data, result, experiment,
citation, quantitative relationship, significance, or mechanistic certainty.
```

## Word Layout Defaults

- Width: available text width.
- Total visual allocation including title/caption: normally about `25%` of the
  usable page, adaptable to about `15–25%`.
- Placeholder text: left-aligned.
- Figure caption: Arial `9–9.5 pt`, left-aligned.
- Narrow text beside a figure: left-aligned.
- Keep the placeholder and caption together; do not split the one-cell row.
- Use a thin border and optional light neutral shading.
- Do not use a floating shape unless the controlling template requires it and
  rendered inspection confirms stable anchoring.

Omit or shrink the placeholder when it would violate an official page limit,
displace mandatory content, duplicate another figure, or add no explanatory
value.

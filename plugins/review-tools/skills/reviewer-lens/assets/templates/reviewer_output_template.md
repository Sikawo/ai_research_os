# Reviewer Lens Output

Use `plugins/review-tools/skills/reviewer-lens/assets/templates/review_response_format.md` as the global default
logic for substantive reviewer-lens responses. This expanded template may be
used when a full multi-role review is useful, but it must preserve:

- Locked reviewer verdict
- Main reviewer risk
- Verdict update assessment when the user pushes back
- Reviewer / Editor / Strategist separation
- Suggested revision when useful
- What would change the reviewer's mind

Shorter responses may compress the format, but they must not drop the locked
reviewer logic.

## 8. User Concern Validation

Classify each user-supplied concern as one of:

- Valid and important
- Valid but secondary
- Overstated
- Weakly supported
- Not aligned with reviewer profile

If the user is pushing back on a prior critique, also apply the mandatory
verdict update labels:

- `Verdict unchanged`
- `Verdict partially updated`
- `Verdict updated`

State why the pushback does or does not change reviewer risk, and what would
change the reviewer's mind.

## 9. Application Writing / English Review

Assess:

- Grammar
- Syntax
- Paragraph flow
- Logical transitions
- Application-appropriate tone
- Reviewer readability
- Concise but specific wording
- Overclaiming
- Vague or inflated language
- Application-style phrasing

Native-level application prose pass:

- Sentences that sound unnatural or non-native
- Sentences that sound too generic, inflated, or AI-like
- Phrases that are grammatically correct but strategically weak
- Places where the prose should sound more like a careful senior scientist
- Suggested native-like alternatives, preserving scientific meaning

## 10. Suggested Revisions

Separate into:

- Scientific/content revision
- Institution-fit revision
- English/tone/flow revision

For English/tone/flow revisions, separate:

- Minimal edit: preserves the user's wording as much as possible
- Stronger application edit: improves reviewer-facing clarity and rhythm
- Warning: any change that risks altering scientific meaning

# Reviewer Lens Response Format

This is the default output logic for any substantive reviewer-lens response.
Shorter responses may compress the sections, but the logic must remain.

```text
A. Locked reviewer verdict
- Verdict: KEEP / REVISE / HIGH RISK / CUT
- Confidence: low / medium / high

B. Main reviewer risk
- What would a critical reviewer worry about?

C. User pushback / new information assessment
- Verdict unchanged / Verdict partially updated / Verdict updated
- Why this does or does not change the reviewer-risk assessment

D. Reviewer / Editor / Strategist separation
- Reviewer: independent concern
- Editor: concrete textual fix
- Strategist: which risk is worth taking and which should be avoided

E. Suggested revision
- Provide revised wording when useful

F. What would change my mind
- Specify what evidence, constraint, or framing would change the verdict
```

## Use Notes

- Use section C whenever the user has pushed back, supplied new information, or
  asked whether a prior critique still holds.
- If there is no user pushback yet, section C may say `No pushback assessed yet`
  or may be omitted in a compressed response.
- The Reviewer role protects independent judgment.
- The Editor role proposes concrete wording.
- The Strategist role decides which reviewer risks are worth taking.
- Do not let the Editor role erase the Reviewer role's concern.
- Do not let the Strategist role become appeasement.

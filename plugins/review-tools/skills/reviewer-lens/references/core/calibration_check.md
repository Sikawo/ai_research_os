# Calibration Check

End reviewer-mode outputs with a calibration check. Use it to audit the review before giving final recommendations.

## Checklist

- Did the review independently identify reviewer concerns before using user-supplied concerns?
- Did it over-accommodate the user?
- Did the reviewer axis drift?
- Did it change priorities without new evidence?
- If the user pushed back, did the review use `Verdict unchanged`, `Verdict partially updated`, or `Verdict updated`?
- Did it state what would change the reviewer's mind?
- Are criticisms supported by the reviewer profile or application text?
- Did it miss obvious concerns this reviewer type should notice?
- Is the critique too harsh, too soft, or balanced?
- What should the applicant not over-correct?
- Are writing and style suggestions separated from scientific/content critiques?
- Did the review avoid fabricating citations, reviewer opinions, institutional policies, or institutional facts?

## Calibration Result

State whether the review is:

- Balanced
- Too soft
- Too harsh
- Under-evidenced
- Over-anchored on user concerns
- In need of a narrower reviewer profile

If the review needs adjustment, briefly say what changed and why.
